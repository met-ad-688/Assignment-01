1 Submission Validation and Setup

This assignment uses a private API key to create one Excel workbook for your responses. The first run creates a dated workbook in research_submissions/. Later runs reuse that same workbook, so you can safely rerun this document without overwriting your work.

  • Update the .env.example file in this folder with your Employability API key and rename it to .env.
  • Update the EMPLOYABILITY_API_KEY value with your Employability API key from the previous step.
  • Run the following code chunk to verify that your API key is working.
  • Do not run the code chunk below this one until you have updated your API key.
EMPLOYABILITY_API_KEY=replace_with_your_student_api_key
EMPLOYABILITY_API_BASE_URL=https://met-employability-services.azurewebsites.net
EMPLOYABILITY_API_PATH_PREFIX=/met-career-match
RESEARCH_ASSIGNMENT_CODE=M01_A_emplo

Do not commit .env, API keys, screenshots of keys, or generated response files unless your instructor explicitly asks for them.
